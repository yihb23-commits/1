# 第一题循迹程序

本工程使用 STM32F103C8T6 标准外设库和 Keil ARMCC5，实现 A→B 自动停车与 A→B→C→D→A 绕场一圈停车，不需要 MaixCAM。八路灰度负责循迹和角点识别，双轮编码器负责速度、距离与转角估计。

程序已写入原工程，打开 `1.uvprojx` 编译，输出 `Objects/1.hex`。`Ctrl+Shift+B` 也可使用原有 VS Code 编译任务。程序参数是初始值，编译通过不能证明实车能通过测试。

## 参数与首次配置

`user/agv_config.h` 集中保存参数，未知信息在代码中以 `TODO` 注明。

| 参数 | 当前值 | 含义 |
|---|---|---|
| 车轮半径 | 0.033 m | 用户提供 |
| 驱动轮中心距 | 0.1192 m | 用于差速与转角计算 |
| 编码器 PPR | 13 | 轴位置、减速比、计数定义待确认 |
| 万向轮左右间距 | 0.060 m | 不用于差速运动学 |
| 每车轮一圈计数 | 0 | 必须实测或从厂家参数换算 |
| 灰度接口 | 八路模拟量 | 假设值，可切换为八路数字量 |
| 灰度阵列到驱动轮轴前伸 | 0.060 m | 假设值，必须测量，与万向轮间距无关 |

**默认电机不允许发车。** 确认接线后将 `AGV_HARDWARE_CONFIRMED` 改为 `1`，并填入 `AGV_COUNTS_PER_WHEEL`。上电不会自动行驶，必须按启动键。

编码器 TI12 模式对 A/B 两相进行四倍频计数。如果厂家所写的 13 是电机轴上单通道每圈完整脉冲数，则：

```text
每车轮一圈计数 = 13 × 减速比 × 4
轮子每个计数距离 = 2π × 0.033 / 每车轮一圈计数
右转角度（弧度）=（左轮距离 - 右轮距离）/ 0.1192
```

如果厂家已将四倍频包含在 13 中，不要再乘 4。可以禁用电机输出，用调试器观察 TIM2/TIM3 的 CNT，手转车轮十圈，计算计数差除以十；计数器发生回绕时要补偿 65536，或分圈记录。前进方向两侧计数都应为正，否则调整对应 `AGV_ENCODER_*_SIGN`。

## 默认接线

以下是本程序提出的接线方案，并非已经确认的实际接线。信号必须与 STM32 的输入电平兼容，ADC 输入不得高于 VDDA；电机、主控、传感器共地，电机电源不能直接接入 MCU 供电引脚。确认电机额定电压及堵转电流适合电源和 TB6612。

| 功能 | STM32 引脚 | 备注 |
|---|---|---|
| 灰度通道 0～5 | PA0～PA5 | ADC 通道 0～5；默认从左往右 |
| 灰度通道 6、7 | PB0、PB1 | ADC 通道 8、9 |
| 左编码器 A、B | PA15、PB3 | TIM2 部分重映射 1 |
| 右编码器 A、B | PA6、PA7 | TIM3 |
| 左 PWMA | PB6 | TIM4 CH1，20 kHz |
| 左 AIN1、AIN2 | PB4、PB5 | TB6612 |
| 右 PWMB | PB7 | TIM4 CH2 |
| 右 BIN1、BIN2 | PB8、PB9 | TB6612 |
| 驱动 STBY | PB10 | 建议外接下拉，复位时保持电机禁用 |
| 启动／停止按钮 | PB12 | 按下接 GND |
| 白底校准按钮 | PB13 | 按下接 GND |
| 黑底校准按钮 | PB14 | 按下接 GND |
| 模式选择 | PB15 | 悬空／高电平为 A→B，接 GND 为一圈 |
| 板载 LED | PC13 | 默认低电平点亮 |
| SWD | PA13、PA14 | 保留；JTAG 已禁用以释放 PA15、PB3、PB4 |

如果是八路比较器数字输出，将 `AGV_GRAY_ANALOG` 改为 `0`，接线沿用上述八个灰度引脚，按实际黑线电平设置 `AGV_GRAY_BLACK_LOW`。数字模式不需要软件黑白校准，但需要调好模块比较器阈值。UART/I2C 型模块需要另外改写读取驱动。

## 校准和发车

1. 架空车轮检查电机方向与编码器方向。两轮前进时，`delta_left`、`delta_right` 都应为正；右转时左轮前进、右轮后退。
2. 模拟量模式下，将整个八路阵列置于均匀白底，按白底校准键；再置于覆盖所有探头的黑色校准材料上，按黑底校准键。校准值存在 RAM，每次断电重做。校准材料只用于调试，不在比赛赛道上加标记。
3. 每一路黑白 ADC 差值须至少达到 `AGV_GRAY_MIN_SPAN`；黑线原始值偏高或偏低均可，归一化自动处理。校准后调试器中的 `agv_input_debug.gray[]` 应为白底接近 0、黑线接近 1000。
4. 设置模式，将小车放在 A，车头沿 AB，驱动轮轴尽量对准 A 点，车头灰度阵列压在 AB 上。位置不同会影响首边距离判断。
5. 按启动键发车。运行时再次按启动键会停车；测试时遵守题目不允许人工干预的要求。

LED 待机慢闪、运行常亮、完成熄灭、故障快闪。Keil Watch 可观察 `agv_debug` 和 `agv_input_debug`；`agv_debug.fault` 给出配置、丢线、转弯超时等具体原因。`agv_input_debug.gray_raw[]` 提供原始 ADC 值（数字模式为 0/1），便于记录黑白读数。

## 控制逻辑和调参

控制周期为 10 ms，灰度黑线强度加权得到 -1～+1 的偏差。正偏差表示线在右侧，PD 输出右转角速度，再转换为两轮目标速度。两轮速度 PI 加前馈输出有符号 PWM，包含输出限幅与积分抗饱和。

```text
待机 → 循迹 → 角点确认 → 低速前移 → 原地右转 → 新边捕线 → 循迹
                        └ 到达任务终点 → 刹车停车
```

角点默认判据为：右侧最后两路均黑、中心至少一路黑、总计至少四路黑，连续三次成立，并且已行驶至少 0.65 m。这仅是默认识别规则，必须按实际探头间距、线宽、安装高度检查读数后调整。右侧单个探头见黑不能直接认作角点。

A→B 在首个角点停止。一圈模式在 B、C、D 各右转一次，在第四个角点 A 停止，不再转向 AB。每次完成转弯后重置边距离，防止重复计数；发车点 A 因距离门限不会计入。

转弯前先低速走 `AGV_CORNER_ADVANCE_M`，使轮轴接近顶点。左轮正转、右轮反转，编码器估计右转角；超过约 60°后，中心见线且外侧脱离横线连续四次才进入下一边。转角超过约 110°或 2.5 s 未捕获则停车。角度由里程估计，轮胎打滑会产生误差。

终点停车前移量由 `AGV_STOP_ADVANCE_M` 配置，默认检测角点即刹车。最终停车误差还包含角点确认时的前进量和惯性滑行，必须实车测量。车体是否始终压线应从上方验证，传感器／编码器不能直接判断车体投影。

调参顺序：先核对计数和正负号，再调单轮速度 PI，接着调直线 PD，然后单独调一个直角，最后调两种模式停车。优先降低速度进行首次落地测试。正常巡航初始为 0.22 m/s，接近角点降至 0.10 m/s；一圈是否小于 30 s 必须实际计时。

丢线连续 80 ms 停车，不执行大范围找线；漏检角点且该边里程超过 1.20 m 停车；任务 10 s／30 s 超时停车。低速前移／转弯均有超时保护。控制循环明显落后时故障停车。

## 文件

- `main.c`：按钮操作、固定周期调度、调试变量。
- `user/agv_config.h`：实测参数、接口假设与调参项。
- `user/agv_control.c/.h`：灰度 PD、速度 PI、任务状态机。
- `user/agv_board.c/.h`：ADC／数字灰度、编码器、PWM、按钮、LED。
- `user/stm32f10x_it.c`：1 ms SysTick 时基。

工程中原有库文件路径指向上一层 `../library`，现已改为工作区内的 `./library`，并启用了 HEX 输出。

主控适配检查、晶振注意事项、可调参数和待填写信息见 `STM32F103C8T6_适配与待补参数.txt`。用户已确认轮趣 C03C 系统板带 8 MHz 外部晶振，项目显式定义 `HSE_VALUE=8000000`，沿用 PLL×9、72 MHz 配置。PC13 低电平 LED 和 PA15/PB3/PB4 可接线也已确认。

用户已填写两台 MG513XP28 电机额定 12 V；灰度模块 5 V 供电，同时提供模拟和数字输出，左到右 L1～L8，探头间距 8 mm。程序继续选用模拟输出，其输出电压仍待确认；编码器每圈计数、实际接线和灰度前伸距离也仍待补。详细测量步骤见 `循迹参数_获取与测量教程.txt`。
